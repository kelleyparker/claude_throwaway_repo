Install WSL from PowerShell (admin) if needed:

wsl --install -d Ubuntu-24.04
wsl --set-default-version 2
wsl -l -v      # confirm VERSION is 2

Optionally cap resources with %UserProfile%\.wslconfig (template: templates/.wslconfig).

2. Enable systemd

Jenkins runs as a service, so WSL needs systemd. Inside Ubuntu:

git clone <this-repo> && cd claude_throwaway_repo
./scripts/00-enable-systemd.sh

Then in PowerShell:

wsl --shutdown

Reopen Ubuntu and confirm: ps -p 1 -o comm= prints systemd.

3. Install Jenkins

./scripts/01-install-jenkins.sh

The script installs Java 21, Git, Docker, adds the Jenkins LTS apt repo, installs and starts Jenkins, and prints the initial admin password. Manual equivalent:

sudo apt update && sudo apt install -y fontconfig openjdk-21-jre git docker.io
# Jenkins rotates signing keys: fetch both so apt can verify the repo
for y in 2023 2026; do
  curl -fsSL https://pkg.jenkins.io/debian-stable/jenkins.io-$y.key
done | sudo tee /etc/apt/keyrings/jenkins-keyring.asc >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/jenkins-keyring.asc] https://pkg.jenkins.io/debian-stable binary/" \
  | sudo tee /etc/apt/sources.list.d/jenkins.list
sudo apt update && sudo apt install -y jenkins
sudo usermod -aG docker jenkins
sudo systemctl enable --now jenkins

4. First-time setup

  1. Open http://localhost:8080 in your Windows browser (WSL2 forwards localhost).
  2. Paste the password: sudo cat /var/lib/jenkins/secrets/initialAdminPassword
  3. Choose Install suggested plugins, create an admin user, confirm the URL.
  4. Run ./scripts/03-verify.sh to health-check the install.

Changed the port? Edit Environment="JENKINS_PORT=..." via sudo systemctl edit jenkins, then restart.

5. Plugins

Create an API token (User → Security → API Token), then:

export JENKINS_USER=admin JENKINS_TOKEN=<token>
./scripts/02-install-plugins.sh

The list lives in templates/plugins.txt (Pipeline, Git, Docker Pipeline, GitHub, Configuration as Code, Blue Ocean, …).

6. Your first pipeline

  1. Copy templates/Jenkinsfile to the root of your project repo and push.
  2. Jenkins → New Item → Multibranch Pipeline → add your Git repo as a branch source.
  3. Click Scan Repository Now; builds run for every branch with a Jenkinsfile.

The template has Checkout → Build → Test → Docker Build → Deploy (main only), timeouts, log rotation and workspace cleanup.

7. Config as Code (optional)

Make the setup reproducible with templates/jenkins.yaml:

sudo mkdir -p /var/lib/jenkins/casc
sudo cp templates/jenkins.yaml /var/lib/jenkins/casc/
sudo systemctl edit jenkins
#   [Service]
#   Environment="CASC_JENKINS_CONFIG=/var/lib/jenkins/casc/jenkins.yaml"
#   Environment="ADMIN_PASSWORD=change-me"
#   Environment="JAVA_OPTS=-Djenkins.install.runSetupWizard=false"
sudo systemctl restart jenkins

8. Webhooks from GitHub

GitHub can't reach localhost. Either use pollSCM (the template default) or expose Jenkins with a tunnel such as cloudflared tunnel --url http://localhost:8080 or ngrok, then add a webhook to <tunnel-url>/github-webhook/. Only expose Jenkins with authentication enabled.

9. Troubleshooting

SymptomFix
System has not been booted with systemdStep 2; ensure WSL2 and run wsl --shutdown.
localhost:8080 unreachablesudo systemctl status jenkins, journalctl -u jenkins -e; try the WSL IP from hostname -I.
permission denied on docker.socksudo usermod -aG docker jenkins && sudo systemctl restart jenkins
Out of memory / slow buildsRaise memory in .wslconfig.
Jenkins service fails instantly; log says "older than the minimum required version (Java 21)"sudo apt-get install -y openjdk-21-jre, set it as default with sudo update-alternatives --config java, then sudo systemctl reset-failed jenkins && sudo systemctl restart jenkins.
NO_PUBKEY / "repository is not signed" on apt updateJenkins rotated its signing key. Re-run 01-install-jenkins.sh (it now fetches the 2023 and 2026 keys), then sudo apt-get update.
Jenkins gone after WSL stopsWSL shuts down when idle; keep a terminal open or run wsl -d Ubuntu --exec sleep infinity.
Slow file I/OKeep workspaces in /var/lib/jenkins or ~, not /mnt/c.
